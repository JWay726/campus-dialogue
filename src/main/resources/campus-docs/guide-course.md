# 选课与培养方案

## 选课流程
每学期分三轮选课：
1. 第一轮（预选）：按培养方案预排，不限容量，抽签决定。
2. 第二轮（正选）：先到先得，名额满即止。
3. 第三轮（补退选）：开学前两周内进行，可退可补。

## 学分要求
毕业需修满培养方案规定总学分（一般本科 150—160 学分），含通识教育、学科基础、专业核心、实践环节与创新创业学分。

## 退课与改选
开学两周内可自由退课；两周后原则上不退，特殊情况经任课教师与学院同意方可。
未按期选课自行旁听不计学分。

## 课程冲突与免修
课程时间冲突需提交冲突选课申请。已通过同级或更高级考试的可申请课程免修（政治、体育、实验课除外）。

## 学业预警
学期所得学分低于 15 学分触发学业预警，学院安排学业导师帮扶。
