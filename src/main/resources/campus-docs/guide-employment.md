# 就业指导与毕业流程

## 就业指导
就业指导中心提供简历修改、模拟面试、招聘会信息。每年春、秋季举办大型双选会。
「就业信息网」发布岗位，学生在线投递。

## 三方协议
毕业生与用人单位、学校签订三方就业协议，确定户口、档案去向。毁约需办理解约手续并承担相应责任。

## 毕业去向登记
离校前在「毕业去向登记系统」填报升学、就业、创业、待就业等去向，作为派遣依据。

## 档案与户口
- 档案：就业者转至用人单位或人才市场；升学者转至录取院校；未就业可暂存学校两年。
- 户口：自愿迁移，迁移证有效期 30 天，逾期需重新办理。

## 毕业审核
学院与教务处审核学分、体测、外语与计算机要求，达标者颁发毕业证与学位证。
未达标者视情况结业或延长学习年限。
