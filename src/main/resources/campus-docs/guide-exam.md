# 考试与成绩管理

## 考试安排
期中、期末考试由教务处在「教务系统」统一排定，考前两周公布考场。
英语四六级、计算机等级考试等社会化考试另行报名。

## 成绩与绩点
百分制成绩按学校绩点公式换算（如 90—100=4.0，80—89=3.0）。
平均学分绩点（GPA）为推免、评奖、转专业的重要依据。

## 补考与重修
- 必修课不及格可参加开学初补考一次；补考仍不及格须重修。
- 重修随下一年级跟班上课，成绩按实际记载，绩点重新计算。
- 选修课不及格可不重修，另选替代，但需保证总学分达标。

## 缓考
因病或重大事由不能参加考试，须考前提交缓考申请（附证明），批准后随补考进行，缓考成绩按正考记载。

## 成绩复核
对成绩有异议，在成绩公布 5 个工作日内向开课学院提出书面复核申请，由教研室复查。
