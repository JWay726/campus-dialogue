# 宿舍管理与报修

## 入住与分配
新生宿舍由后勤集团按学院、年级统一分配，报到时领取钥匙。
调换宿舍需双方同意后向楼管员申请，经后勤审批。

## 报修
- 水电、家具、空调、网络故障通过「智慧校园」App「报修」模块提交，注明楼栋房号与故障描述，维修人员 24 小时内响应。
- 紧急（漏水、断电）可直拨后勤值班电话。

## 门禁与用电
- 宿舍楼 23:00—次日 6:00 门禁，晚归需登记。
- 额定用电功率约 800W，禁用大功率电器（热得快、电炉等），违规触发断电。
- 电费在「智慧校园」App 充值，欠费自动断电。

## 访客与卫生
访客需在大厅登记并限时离开。每周卫生检查计入文明寝室评比。
