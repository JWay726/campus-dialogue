# 新生报到与注册指南

## 报到时间
每年 9 月 1 日—9 月 3 日为新生报到注册期，逾期需联系学院辅导员办理请假与补报到手续。

## 报到地点
各学院迎新点设在对应学院楼一楼大厅。校本部迎新总站设在第一图书馆广场。

## 必带材料
1. 录取通知书原件
2. 身份证原件及复印件
3. 一寸免冠照片 8 张（蓝底）
4. 党团关系转移介绍信（如需）
5. 个人档案（自带档案的同学）

## 缴费方式
学费、住宿费通过学校财务系统（http://pay.example.edu.cn）在线缴纳，
支持银行卡与微信支付。家庭经济困难学生可申请绿色通道缓缴。

## 宿舍安排
宿舍由后勤集团统一分配，报到当天在迎新点领取钥匙与一卡通。
寝具可自带或在校内服务点自愿购买。

## 常见问题
- 问：录取通知书丢了怎么办？答：联系招生办补办证明，凭身份证与准考证报到。
- 问：可以提前到校吗？答：建议在报到期内到校，提前到校需自行安排临时住宿。
