# 学籍与注册管理

## 学期注册
在校生每学期开学初需完成电子注册。登录「教务系统」核对个人信息、缴纳学杂费后点击「学期注册」。
未注册者不得参加课程学习与考试。因故不能按期注册，应办理暂缓注册手续。

## 休学与复学
- 休学：因病、创业、入伍等可申请，期限一般为 1 年，累计不超过 2 年。需提交申请表及相关证明，学院与教务处审批。
- 复学：休学期满前 1 个月提交复学申请，经审核后编入相应年级。
- 保留入学资格：新生因故可保留入学资格 1 年（如应征入伍保留至退役后 2 年）。

## 退学
学生本人申请退学或达到退学条件（如学业成绩未达标、未经批准连续两周未注册且未请假），由校长办公会研究决定。
退学手续包括结清费用、归还图书与设备、档案转递等。

## 学籍证明
在读证明、学籍在线验证报告可通过「学信网」(chsi.com.cn) 下载，纸质证明在教务处窗口办理。
